## 💡 Sobre o Projeto

O **Cidade Tech** é uma solução criada para aproximar a comunidade das decisões do seu bairro ou cidade. Através da plataforma, associações de moradores e conselhos municipais podem lançar consultas e propostas públicas transparentes, enquanto os cidadãos participam ativamente votando e acompanhando os resultados oficiais e o andamento das melhorias comunitárias.
